Text-to-SQL
Ask a question. Get an answer — no SQL required.
Type a question about your ticket data in plain English. Claude writes the query, runs it, and reads back the result — never the raw SQL, unless you want to see it.

Which team has the most open tickets?

Examples: "How many critical tickets are still open?" · "Avg resolution time for Network tickets?"
What's under the hood
01
Schema-aware generation. Claude Haiku is given the actual column names and real distinct values in your ticket table, then converts the question into a single SQLite query.
02
Safety-checked before it runs. Only SELECT statements are allowed — anything containing DROP, DELETE, UPDATE, INSERT, ALTER, or similar is blocked outright.
03
Read back in plain English. Raw query results are handed to Claude a second time to produce a concise, natural-language answer — the SQL stays available, but tucked behind an expander.
